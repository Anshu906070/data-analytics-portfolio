### 📌 Day 02 – Hotel Booking Cancellation Analysis

**Project:** Hotel Booking Cancellation Analysis

An interactive Excel dashboard analyzing hotel booking data to identify booking patterns, cancellation trends, hotel-type performance, guest-type behavior, and room-status distribution.

**Key Features:**

* Total bookings and cancellations analysis
* City Hotel vs. Resort Hotel comparison
* Guest-type analysis
* Monthly booking and cancellation trends
* Room-status analysis
* PivotTables and PivotCharts
* Interactive slicers
* KPI cards and dashboard visualization

**Key KPIs:**

* Total Bookings: **119,390**
* Total Cancellations: **44,224**

➡️ **[View Day 02 – Hotel Booking Cancellation](./Day-02-Hotel-Booking-Cancellation/)**
