# Hotel Booking Cancellation Analysis – Excel

## 📊 Project Overview

This project analyzes hotel booking data to identify booking patterns, cancellation trends, hotel-type performance, guest-type behavior, and room-status information using **Microsoft Excel**.

An interactive Excel dashboard was created using **PivotTables, PivotCharts, slicers, and data visualization techniques** to convert raw hotel booking data into meaningful business insights.

## 🎯 Objectives

* Analyze total hotel bookings and cancellations
* Identify cancellation patterns across different hotel types
* Compare bookings and cancellations by guest type
* Analyze monthly booking and cancellation trends
* Understand room-status distribution
* Build an interactive Excel dashboard for decision-making

## 🛠️ Tools & Technologies

* Microsoft Excel
* PivotTables
* PivotCharts
* Slicers
* Excel Dashboard
* Data Cleaning & Transformation
* Data Analysis
* Data Visualization

## 📈 Key KPIs

| KPI                   |   Value |
| --------------------- | ------: |
| Total Bookings        | 119,390 |
| Total Cancellations   |  44,224 |
| City Hotel Bookings   |  79,330 |
| Resort Hotel Bookings |  40,060 |
| Desired Room Status   | 110,198 |
| Undesired Room Status |   9,192 |

## 📊 Dashboard Analysis

### 1. Guest Type Analysis

The dashboard compares total guests/bookings and cancelled bookings across:

* Couple
* Family
* Other
* Single

Couples account for the largest share of bookings as well as cancellations.

### 2. Hotel Type Analysis

The analysis compares:

* City Hotel
* Resort Hotel

City Hotels contribute the larger proportion of total bookings and cancellations.

### 3. Monthly Booking & Cancellation Analysis

Monthly trends are analyzed to identify periods with higher booking volumes and cancellation activity.

The dashboard provides a month-wise comparison of total bookings against cancelled bookings.

### 4. Room Status Analysis

Room status is divided into:

* Desired
* Undesired

The analysis compares cancelled bookings and total bookings across room-status categories.

## 💡 Key Insights

* City Hotels account for approximately **66% of total bookings**.
* Resort Hotels account for approximately **34% of total bookings**.
* Couple bookings represent the largest guest category.
* August records the highest monthly booking volume in the analyzed data.
* The majority of bookings have a **desired room status**.
* The dashboard allows users to filter the analysis using interactive slicers such as arrival year, country, and booking changes.

## 📌 Excel Features Used

* PivotTables
* PivotCharts
* Slicers
* KPI Cards
* Interactive Filters
* Bar/Column Charts
* Pie Charts
* Dashboard Formatting
* Conditional Formatting
